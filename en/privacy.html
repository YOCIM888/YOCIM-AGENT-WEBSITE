Privacy Policy

Last updated: November 18, 2026. YOCIM AGENT is a local-first desktop app. This policy explains where data lives and when the app connects to the network.

1. Data stored locally

Projects, sessions, messages, tool calls, settings, audit logs, and token usage are stored in your data directory (Electron userData; on Windows typically %APPDATA%\YOCIM AGENT). You can change this directory in Settings → Storage; the change takes effect after a restart.

Each provider's API key is encrypted with Electron safeStorage before being written to local settings. The interface only reads whether a key is configured — it never returns the key to the renderer or to this website.

2. What leaves your device

  • Your configured model provider: conversation content, tool context, and attachments go to the provider you choose (for example DeepSeek, OpenAI, Ollama, or a custom endpoint).
  • Web search: search terms go to Tavily only if you configure and enable a Tavily key.
  • Update check: the app queries GitHub Releases for the latest version after startup. Ignored versions are stored locally.
  • Image generation and remote workspaces are opt-in; destinations are determined by the endpoints you configure.

The app has no ads, third-party analytics, or telemetry, and does not upload local conversations to a YOCIM-operated server.

3. Website and download page

This website is static and does not set advertising or analytics cookies. The download page requests the latest release from the GitHub API and caches it in localStorage for about six hours to speed up repeat visits and reduce rate-limit errors. Clearing site data in your browser removes that cache.

External links to GitHub, Cursor, Cline, and others are governed by their own privacy terms.

4. Browser tools and cleanup

AI browser tools use dedicated yocim-browser-* storage partitions. Settings → Browser → Clear browser data only removes those partitions; your default browser profile is never touched.

5. Your control and contact

You can remove all local data by deleting the data directory. Uninstalling the app does not delete it automatically. For privacy questions or removal requests, email yocim666@outlook.com or open a GitHub Issue.
