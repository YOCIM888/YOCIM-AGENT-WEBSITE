Changelog

Recent versions are synced from GitHub Releases. If the network is unavailable, the static entry below remains visible; full notes live on the release page.

v0.1.8

Published November 18, 2026

This release focuses on fixes and hardening: closed a run_command allowlist bypass and shell injection risks, added SSH host key verification (trust on first use, blocked when the fingerprint changes), added Anthropic reasoning-signature support, and fixed tool-call id collisions, token under-counting, and the updater picking an installer for the wrong architecture. Upgrading from 0.1.x keeps local sessions, settings, and API keys.
