Frequently asked questions

Common questions about install warnings, key security, offline use, and product positioning. Still stuck? Use the email or GitHub Issues link in the footer.

Windows SmartScreen says "Unknown publisher". Is it safe?

The installers are not code-signed yet, so SmartScreen shows "Unknown publisher". Download only from this site or GitHub Releases ↗, verify the file name and SHA-256, then choose More info → Run anyway. macOS builds are not notarized; right-click the app and choose Open on first launch.

Where do my API keys go?

API keys are encrypted with Electron safeStorage and stored locally. The UI only reads whether a key is configured. Requests go only to the model service or endpoint you configure; YOCIM does not operate a proxy. See the Privacy Policy.

Can I use it offline?

The app and local data work offline. With a local model such as Ollama, conversations can be fully offline. Cloud models, web search, and update checks need a network connection. Installation and updates require downloading from GitHub Releases.

How is YOCIM AGENT related to Cursor?

They are unrelated products. YOCIM AGENT is an independent open-source desktop app, not a Cursor fork or extension, and does not depend on Cursor proprietary services. You can use both; sessions and settings are not shared. See the comparison.

Where is my data, and how do I delete it?

Projects, sessions, messages, settings, and audit logs live in the Electron userData directory, typically %APPDATA%\YOCIM AGENT on Windows. Change it in Settings → Storage and restart. Delete the whole directory to remove local data; uninstalling does not delete it automatically.

How do I update or uninstall?

The app checks for new versions on startup. You can also download the latest installer from the changelog or GitHub Releases and install over the old version; sessions, settings, and API keys are preserved. On Windows use Settings → Apps, on macOS move the app to Trash, and Scoop users can run scoop update yocim-agent.
