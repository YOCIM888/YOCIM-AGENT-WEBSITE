Install

All methods use the same GitHub Release assets. Manifests ship with the repository; inclusion in third-party official sources still requires their review.

winget (Windows)

The manifest currently installs from a local file. Make sure the App Installer from Microsoft Store is installed, then allow local manifests:

winget settings --enable LocalManifestFiles

Download the manifest and install

curl -L -o YOCIM.YOCIMAGENT.yaml https://raw.githubusercontent.com/YOCIM888/YOCIM-AGENT/main/packaging/winget/YOCIM.YOCIMAGENT.yaml
winget install --manifest .\YOCIM.YOCIMAGENT.yaml

The manifest uses the NSIS silent switch /S. Once accepted into the winget community repository, run winget install --id YOCIM.YOCIMAGENT -e.

Homebrew Cask (macOS)

The cask includes both Apple Silicon and Intel dmg URLs with SHA-256 checks. Install the local cask file for now:

curl -L -o yocim-agent.rb https://raw.githubusercontent.com/YOCIM888/YOCIM-AGENT/main/packaging/homebrew/Casks/yocim-agent.rb
brew install --cask ./yocim-agent.rb

Builds are not notarized, so macOS may block the first launch: right-click the app and choose Open, or allow it in System Settings. After an official tap accepts the cask, use brew install --cask yocim-agent.

Scoop (Windows)

Scoop can install a manifest directly from a public URL — no extra bucket required:

scoop install https://raw.githubusercontent.com/YOCIM888/YOCIM-AGENT/main/packaging/scoop/yocim-agent.json

Update later with scoop update yocim-agent. The manifest extracts the NSIS installer with 7-Zip to avoid writing outside the Scoop directory.

Direct download

If you prefer not to use a package manager, get the Windows installer, macOS dmg, and Linux AppImage from the changelog or the latest release ↗. Release assets include SHA-256 digests for verification.
