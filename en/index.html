Core features

Not a replacement for your editor — a place that puts you, the model, your tools, and your project together.

01

Multiple models

DeepSeek, Qwen, Kimi, Claude, Gemini, Grok, local Ollama, and any OpenAI-compatible endpoint.

02

Three-pane workspace

Project sessions on the left, chat in the middle, files and audit on the right. Collapsible panels and persisted layout.

03

Tools with approvals

File edits, search, and commands go through an approval queue. Manual / Auto / Open modes, with guards always enforced.

04

Built-in editor

Monaco tabs, save-conflict prompts, external-change detection, and selection-to-chat.

05

Project-based sessions

One directory, one project. Pin, archive, or move sessions; everything persists in local SQLite.

06

Workspace search & replace

Streaming ripgrep search with regex and include/exclude rules, plus a diff preview before replacing.

07

Remote workspaces

Connect through WSL or SSH to browse, edit, search, and run tasks remotely.

08

Source control

Stage, commit, switch branches, pull and push, with a graphical commit graph and file statistics.

09

AI-operable browser

A visible Chromium view inside the chat pane. The agent navigates, screenshots, reads the DOM, dispatches input and waits through CDP; an in-view console aggregates logs and an action audit, with pause / take over / resume controls.

Per-user Windows install. The repo-hosted manifest can be installed directly by URL — no extra bucket needed.

Install guide

Creates a Start menu shortcut after installation.

Installation notes

Unsigned installers

There is no code-signing certificate yet. Windows SmartScreen may show "Unknown publisher" — choose More info → Run anyway. macOS builds are not notarized; right-click and choose Open on first launch.

Data stays local

Sessions, messages, and settings live in a local SQLite database. API keys are encrypted with OS secure storage. Requests only go to the model service you configure.

Getting started

Add a model provider and API key in Settings, pick a project directory, and start a conversation. See the FAQ for details.
