常见问题

关于安装提示、密钥安全、离线使用与产品定位的几个高频问题。没有找到答案？欢迎通过页脚邮箱或 GitHub Issues 提问。

Windows SmartScreen 提示「未知发布者」，安全吗？

当前安装包未购买代码签名证书，因此 SmartScreen 会显示「未知发布者」。请只从本项目 GitHub Releases ↗ 或本官网下载，核对文件名与 SHA-256 后选择「更多信息 → 仍要运行」。macOS 构建未公证，首次打开请在 Finder 中右键选择「打开」。

API Key 会上传到哪里？

API Key 经 Electron safeStorage 加密后保存在本机，界面只能读取「是否已配置」。请求只发送到你选择的模型服务或你自行配置的端点；YOCIM 不运营中转服务，也不会收集你的密钥。详见 隐私政策。

可以离线使用吗？

应用本体和本地数据可离线使用；配置本地 Ollama 等模型后，对话也能完全离线。云端模型、联网搜索、更新检查需要网络。首次安装和后续更新必须从 GitHub Releases 下载安装包。

YOCIM AGENT 和 Cursor 是什么关系？

两者没有隶属关系。YOCIM AGENT 是独立的开源桌面应用，不是 Cursor 的分支或插件，也不依赖 Cursor 的专有服务。你可以同时使用它们，项目会话和设置互不共享。首页有 功能对比。

数据保存在哪里，如何删除？

项目、会话、消息、设置和审计日志保存在 Electron userData 目录，Windows 通常为 %APPDATA%\YOCIM AGENT。可在「设置 → 存储」更改目录，重启生效。删除整个目录即可清除本地数据；卸载应用不会自动删除它。

如何更新或卸载？

应用启动后会检查新版本；也可从官网更新日志或 GitHub Releases 下载最新安装包覆盖安装，升级会保留本地会话、设置与 API Key。Windows 可在系统设置中卸载，macOS 将应用拖到废纸篓，Scoop 用户可运行 scoop update yocim-agent。
