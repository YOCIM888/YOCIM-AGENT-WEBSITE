安装方式

所有安装方式都来自同一组 GitHub Release 资产。清单文件随主仓库提供；第三方官方源收录仍需对应仓库审核。

winget（Windows）

清单当前以本地文件方式安装。先确保已安装 Microsoft Store 的「应用安装程序」，并允许本地清单：

winget settings --enable LocalManifestFiles

下载清单并安装

curl -L -o YOCIM.YOCIMAGENT.yaml https://raw.githubusercontent.com/YOCIM888/YOCIM-AGENT/main/packaging/winget/YOCIM.YOCIMAGENT.yaml
winget install --manifest .\YOCIM.YOCIMAGENT.yaml

清单使用 NSIS 静默安装参数 /S。待 winget 社区仓库收录后，可直接运行 winget install --id YOCIM.YOCIMAGENT -e。

Homebrew Cask（macOS）

Cask 同时包含 Apple Silicon 与 Intel 的 dmg 地址和 SHA-256 校验值。当前以本地 cask 文件安装：

curl -L -o yocim-agent.rb https://raw.githubusercontent.com/YOCIM888/YOCIM-AGENT/main/packaging/homebrew/Casks/yocim-agent.rb
brew install --cask ./yocim-agent.rb

由于构建未公证，macOS 可能阻止首次打开；可在 Finder 中右键应用选择「打开」，或在系统设置中允许。官方 tap 收录后可直接使用 brew install --cask yocim-agent。

Scoop（Windows）

Scoop 可直接从公开 URL 安装清单，无需添加 bucket：

scoop install https://raw.githubusercontent.com/YOCIM888/YOCIM-AGENT/main/packaging/scoop/yocim-agent.json

后续可用 scoop update yocim-agent 更新。清单使用安装包的 7z 解包方式，避免 NSIS 安装器写入 Scoop 目录之外。

直接下载

如果不想使用包管理器，可从 更新日志 或 最新 Release ↗ 获取 Windows 安装包、macOS dmg 与 Linux AppImage。发布资产均带 SHA-256 摘要，可在 Release 页面核对。
