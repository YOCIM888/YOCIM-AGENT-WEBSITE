核心功能

不替代你的编辑器，而是把你和模型、工具、项目放在同一个窗口里。

01

多模型接入

DeepSeek、Qwen、Kimi、Claude、Gemini、Grok、本地 Ollama，以及任意 OpenAI 兼容端点，随时切换。

02

三栏工作区

左侧项目会话、中间对话、右侧文件与审计。面板可折叠、分隔条可拖动，布局状态自动保存。

03

工具调用与审批

读写文件、搜索、执行命令都经过审批队列。手动 / 自动 / 开放三种模式，但路径守卫与危险命令拦截始终生效。

04

内置编辑器

Monaco 多标签编辑，保存冲突提示与外部修改检测，选中代码可直接加入对话。

05

项目化会话

一个目录对应一个项目，会话可置顶、归档、跨项目迁移。全部记录持久化到本地 SQLite。

06

工作区搜索替换

基于 ripgrep 的流式搜索，支持正则、包含排除规则，替换前展示差异预览。

07

远程工作区

通过 WSL 或 SSH 连接远程环境，直接浏览、编辑、搜索与执行任务。

08

源码管理

暂存、提交、切换分支、拉取推送，附带图形化提交图与改动文件统计。

winget

Windows 包管理器。清单已随仓库提供，社区源收录前可用本地清单安装。

winget install --manifest .\YOCIM.YOCIMAGENT.yaml
安装说明

Homebrew Cask

macOS 命令行安装。Cask 文件已提供，官方 tap 收录前可本地安装。

brew install --cask ./yocim-agent.rb
安装说明

同时提供 arm64 与 x64 的 dmg 校验值。

Scoop

Windows 用户级安装。仓库内清单可直接通过 URL 安装，无需额外 bucket。

scoop install https://raw.githubusercontent.com/YOCIM888/YOCIM-AGENT/main/packaging/scoop/yocim-agent.json
安装说明

安装后自动创建开始菜单快捷方式。

安装说明

未签名安装包

安装包暂未购买代码签名证书。Windows SmartScreen 可能提示「未知发布者」，点击「更多信息 → 仍要运行」即可继续；macOS 包未公证，首次打开请在 Finder 中右键选择「打开」。

数据留在本地

会话、消息与设置保存在本机 SQLite 数据库，API Key 通过系统安全存储加密。请求只会发送到你配置的模型服务。

首次使用

打开设置添加一个模型提供商并填入 API Key，选择项目目录后即可新建会话开始对话。详见 常见问题。
