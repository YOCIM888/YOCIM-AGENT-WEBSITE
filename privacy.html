隐私政策

最后更新：2026 年 11 月 18 日。YOCIM AGENT 是本地优先的桌面应用，本政策说明数据保存在哪里，以及什么时候会联网。

1. 本地存储的数据

项目、会话、消息、工具调用记录、设置、审计日志和 token 用量保存在你本机的数据目录（Electron userData，Windows 通常为 %APPDATA%\YOCIM AGENT）。你可以在「设置 → 存储」更换该目录，改动在重启后生效。

每个模型提供商的 API Key 经 Electron safeStorage 加密后写入本地设置，界面只读取「是否已配置」，不会把密钥回传给渲染进程或官网。

2. 会离开设备的内容

  • 你配置的模型服务：对话内容、工具调用上下文与附件会发送到你选择的提供商（例如 DeepSeek、OpenAI、Ollama 或自定义端点）。
  • 联网搜索：只有当你配置并启用 Tavily Key 时，搜索词才会发送给 Tavily。
  • 版本更新检查：启动后向 GitHub Releases 查询最新版本号；忽略的版本号只保存在本机浏览器/应用存储中。
  • 生图、远程工作区等功能由你在设置中显式启用，请求目标由你配置的端点决定。

应用不内置广告、第三方统计或遥测服务，也不会把本地会话内容上传到 YOCIM 运营的服务器。

3. 官网与下载页

官网是静态页面，不设置广告或分析 Cookie。下载页会在浏览器中请求 GitHub API 获取最新 Release 信息，并在 localStorage 中缓存约 6 小时，以加快后续访问并降低被限流的概率。你可以随时清除浏览器站点数据来删除该缓存。

官网中的 GitHub、Cursor、Cline 等外链由各自运营方管理，请查阅其隐私条款。

4. 浏览器工具与数据清理

AI 浏览器工具使用独立的 yocim-browser-* 存储分区。「设置 → 浏览器 → 清除浏览器数据」只清理这些分区，不会触碰你的默认浏览器配置或日常 profile。

5. 你的控制与联系

你可以删除整个数据目录来清除所有本地数据；卸载应用不会自动删除该目录，请按需手动处理。对隐私政策有疑问或需要删除相关反馈，请发邮件至 yocim666@outlook.com，或在 GitHub Issues 中提出。
